# DOJO — лабораторный проект ЭПИ

Учебный план проекта веб-сайта сети компьютерных клубов DOJO. Состав задач и оценки перенесены из отчёта ЛР1; трудоёмкость — наивная оценка, всего 790 чел.-ч.

## Команда по ЛР1

- 2–3 разработчика;
- дизайнер, тестировщик и менеджер проекта с частичной занятостью.

В отчёте ЛР1 не указаны имена участников и их адреса электронной почты, поэтому здесь фиксируются роли, а не вымышленные сотрудники.

## План Scrum

| Спринт | Объём WBS | Оценка | Цель |
|---|---:|---:|---|
| Sprint 1 | 1–6, 21 | 270 ч | Анализ, UI/UX, CI/CD и основные страницы |
| Sprint 2 | 7–10, 17 | 190 ч | Каталог, цены, новости, контакты и backend API |
| Sprint 3 | 11–15 | 200 ч | DOJO Live, меню, бонусы, кейсы и авторизация |
| Sprint 4 | 16, 18–20 | 130 ч | Бронирование, интеграции, тестирование и запуск |

## Релизы

1. Веб-витрина — WBS 1–10 и 21.
2. DOJO Live и backend — WBS 11–15 и 17.
3. Запуск DOJO — WBS 16 и 18–20.

## Ветки разработки

- `main` — базовая версия плана;
- `develop` — интеграционная ветка;
- `sprint/1`, `sprint/2`, `sprint/3`, `sprint/4` — учебные ветки по спринтам.

Фактическая разработка в рамках этой настройки не выполнялась. Статусы задач, помеченные комментариями «Учебная симуляция ЛР2», демонстрируют работу Scrum-процесса в YouTrack.
